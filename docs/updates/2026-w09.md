# Weekly Update: 2026-W09 - Threaded Books & Streaming AI

## Overview
This week marked a significant architectural shift from single-shot AI generation to **collaborative co-authoring**. We've introduced the "Threaded Books" concept and implemented real-time AI streaming capabilities.

## Key Features

### 1. Conversational Threads (with SSE)
We've moved beyond simple request-response AI calls. The system now supports persistent chat threads.
- **Streaming**: AI responses now stream in real-time using Server-Sent Events (SSE).
- **Persistence**: Every conversation is saved to Firestore, allowing users to resume chats later.
- **Title & Pinning**: Users can rename threads and pin important ones for quick access.

### 2. AI Tool Calling
The Gemini provider now supports autonomous tool calling.
- **Image Generation Tool**: While chatting, the AI can trigger the `generate_image` tool. The server automatically generates the image, uploads it to Firebase Storage, and injects a Markdown link into the chat.
- **Book Drafting Tools**: New tools like `draft_book_page` allow the AI to synthesize conversation history into structured book chapters.

### 3. Threaded Books (Collaborative Authoring)
The "Threaded Books" feature allows users to build long-form content (papers, blogs, or full books) through dialogue.
- **Co-Authoring**: Users debate and refine ideas in a thread, then ask the AI to "draft a page" from that context.
- **Background Workers**: Page generation runs as a background job to ensure high-quality, long-form content without blocking the chat.
- **Ordered Assembly**: Books maintain an explicit `pageIds` array to ensure chapters are retrieved in the correct sequence.

## Technical Improvements
- **Firestore Schema Validation**: Implemented schema-based models for Books and Pages, consistent with the Article model.
- **Branch Protection**: Enabled branch protection rules for `develop` and `master` to prevent direct pushes and enforce PR reviews.
- **Storage Optimization**: Standardized image upload paths to `users/<userId>/threads/<threadId>/images/` for better asset management.

## What's Next
- **Book Export**: Implementing PDF/EPUB export for completed books.
- **Page Refinement Tool**: Allowing the AI to rewrite or update specific pages based on new conversation context.
- **Performance Profiling**: Investigating and optimizing database query latency.
