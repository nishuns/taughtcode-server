# v1.0.1 · 03 Feb 2026

**Status**: Completed
**Type**: Feature / Content Engine
**Created**: 2026-02-03

## Description
This release establishes the core infrastructure of the **TaughtCode Server** and introduces the complete **Article Management System**, including an AI-powered generation pipeline, a robust monetization schema, and integration with the documentation system.

## New Features & Achievements

### 1. Core Infrastructure & Architecture
- **Project Setup**: Initialized the project with a robust directory structure following the **Provider-Service-Controller (PSC)** pattern.
- **Firebase Integration**: Configured Firebase Admin SDK with environment-based secrets and connection logic.
- **Model Abstraction**: Created `FirebaseModel`, a Mongoose-like wrapper for Firestore to ensure schema validation (Joi/Custom) and consistent CRUD operations (`findOne`, `findOneAndUpdate`, `findById`).

### 2. Authentication & User Management
- **Auth Middleware**: Implemented `isAuthenticated` and `optionalAuth` middleware supporting Bearer tokens and API Keys.
- **User Profile**: Built the User model, controller, and service handling onboarding (`/onboard`), profile updates (`/me`), and admin actions (deactivate/ban).
- **Security**: Added role-based access control placeholders and secure token verification.

### 3. Article Management System
- **Schema & Models**: Added `Article`, `Review`, and `Tag` models with separate collections for better scalability.
- **Monetization**: Implemented access control for `free`, `paid_single`, `subscription_author`, and `subscription_platform` content.
- **Publishing Flow**: Added an endpoint to publish articles directly into the `/docs/articles` directory.
- **Engagement**: Built a review and rating system with automatic average rating calculation.

### 4. AI Content Engine
- **Service Integration**: Integrated **Google Gemini** as the primary AI provider (`gemini-3-flash-preview` and `gemini-3-pro-preview`).
- **Image Generation**: Implemented native Gemini image generation (`gemini-2.5-flash-image`) with automatic storage and linking.
- **Generation Pipeline**: Created an end-to-end pipeline (`/articles/generate`) that:
    1.  Plans the article structure (JSON).
    2.  Generates and uploads images for each section.
    3.  Writes full content integrating the images.
- **Semantic HTML**: AI output is now high-quality, semantic HTML with professional styling classes (Tailwind-ready).
- **Deep-Dive Mode**: Introduced a comprehensive generation mode for long-form technical guides (8-12 sections).
- **Dynamic Layouts**: Supported diverse layouts including `two-column` grids, `hero` sections, and `quote-blocks`.

### 5. Developer Experience (DX)
- **API Docs**: Fully documented User and Article endpoints.
- **Guides**: Added developer guides for "Defining Models", "Building Services", and "AI Prompt Strategy".
- **"About" Page**: Created a dedicated developer profile page in the docs.
- **Postman Improvements**: Optimized the Pre-request script for smarter Firebase Auth token refresh and expiry handling.

## Technical Details
- **Database**: Firestore (NoSQL)
- **AI Models**: `gemini-3-flash-preview` (Flash), `gemini-3-pro-preview` (Pro), `gemini-2.5-flash-image` (Image)
- **Validation**: Joi
- **Storage**: Firebase Storage
- **Path**: `src/services/articleService.js`, `src/controllers/articleController.js`
- **Branch**: `nischay/articles`
