# v1.0.1 · 03 Feb 2026

**Status**: Completed
**Type**: Feature / Content Engine
**Created**: 2026-02-03

## Description
This release introduces the complete **Article Management System**, including an AI-powered generation pipeline, a robust monetization schema, and integration with the documentation system.

## New Features

### 1. Article Management
- **Schema & Models**: Added `Article`, `Review`, and `Tag` models with separate collections for better scalability.
- **Monetization**: Implemented access control for `free`, `paid_single`, `subscription_author`, and `subscription_platform` content.
- **Publishing Flow**: Added an endpoint to publish articles directly into the `/docs/articles` directory.
- **Engagement**: Built a review and rating system with automatic average rating calculation.

### 2. AI Article Engine
- **Orchestration**: Created a multi-step pipeline for structure generation, image generation, and content writing.
- **Semantic HTML**: Updated AI output from Markdown to high-quality, semantic HTML with professional styling classes.
- **Dynamic Layouts**: Supported diverse layouts including `two-column` grids, `hero` sections, and `quote-blocks`.
- **Deep-Dive Mode**: Introduced a comprehensive generation mode for long-form technical guides (8-12 sections).
- **Image Integration**: Integrated native Gemini image generation with automatic storage and linking.

### 3. Developer Experience (DX)
- **"About" Page**: Created a dedicated developer profile page in the docs.
- **Postman Improvements**: Optimized the Pre-request script for smarter Firebase Auth token refresh and expiry handling.
- **PSC Refactoring**: Aligned all new services with the Provider-Service-Controller pattern and `findOne`/`findOneAndUpdate` logic.
