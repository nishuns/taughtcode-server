# v1.1.0 · Threaded Books & AI Streaming (Current)

**Status**: Completed
**Type**: Major Feature Release
**Created**: 2026-03-17

## Description
This major release transforms TaughtCode from a single-shot article generator into a true collaborative co-authoring platform. It introduces Server-Sent Events (SSE) for real-time AI interactions, autonomous tool calling, and a completely new "Threaded Books" architecture designed for deep-dive research and long-form content creation.

## New Features & Achievements

### 1. Conversational AI & Streaming
- **SSE Streams**: Implemented real-time chunked responses using Server-Sent Events in the `ConversationController`.
- **Persistent Threads**: Introduced the `Conversation` model to store chat history, allowing users to return to complex brainstorming sessions.
- **Provider Support**: Upgraded `GeminiAIProvider` to utilize `@google/genai`'s `generateContentStream` and native function extraction.

### 2. Autonomous Tool Calling
- **Image Generation**: The AI can now autonomously decide to generate an image mid-conversation via the `generate_image` tool. The server creates the asset, uploads it to Firebase Storage, and seamlessly injects the markdown link into the chat stream.
- **Tool Registry**: Established a standardized JSON schema pattern for registering AI tools within the stream context.

### 3. Threaded Books Architecture
- **Hierarchical Data Model**: Built the `Book` and `Page` models. Books support multiple named "Chapters", each containing an ordered array of `pageIds`. Papers support a single nameless chapter flow.
- **Brainstorm-First Workflow**: The AI collaborates without drafting until explicitly commanded (e.g., "Draft this page").
- **Background Content Synthesis**: Integrated drafting into the `JobService`. When drafting is triggered (`draft_chapter_page`), a background worker fetches the entire conversation history to generate profound, context-aware semantic HTML content, including section images.

### 4. User Profile & Media Management
- **Enhanced Schema**: Expanded the user profile to include `coverURL`, `skills`, `gallery`, and `featured` items.
- **Media Support**: Implemented dedicated services for profile picture and cover photo updates with automatic storage handling.
- **Gallery Feature**: Added support for personal media galleries (photos and videos) with isolated storage under `users/<userId>/gallery/`.

### 5. Code & Process Optimization
- **Schema-Based Validation**: Maintained the Mongoose-style `FirebaseModel` approach for all new entities.
- **Asset Isolation**: Improved storage logic to cleanly isolate generated images into `users/<userId>/threads/<threadId>/images/` and `users/<userId>/books/<bookId>/pages/`.
- **Branch Protection**: Enforced Pull Request reviews on `develop` and `master` branches to ensure code stability.
