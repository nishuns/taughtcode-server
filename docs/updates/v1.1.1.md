# v1.1.1 · Integrations & Enhanced Identity

**Status**: Completed
**Type**: Feature / Identity
**Created**: 2026-03-18

## Description
This release focuses on connecting TaughtCode to the broader developer ecosystem and providing users with tools to manage their professional identity and content distribution.

## New Features & Achievements

### 1. Platform Integrations
- **GitHub Integration**: Connect GitHub accounts to fetch and showcase top repositories directly in the profile's "Featured Projects" section.
- **LinkedIn Integration**: Connect LinkedIn profiles to enable professional content syndication.
- **Dynamic Config**: Users can now provide their own Client IDs and Secrets for integrations, moving sensitive configuration into their private profile.

### 2. Social Distribution
- **AI Post Generation**: Added a "Generate with AI" tool to the Article and Book editors. It crafts engaging LinkedIn posts with relevant hashtags based on the content's context.
- **One-Click Sharing**: Directly publish TaughtCode articles and books to your LinkedIn feed.

### 3. Professional Profile Upgrades
- **Featured Projects**: Added a dedicated section for showcasing work, with support for manual entry and automatic GitHub syncing.
- **Identity Expansion**: Support for occupations, detailed bios, technical skill tags, and subject matter expertise.
- **Media Support**: Refined handlers for profile and cover photo updates.

## Technical Details
- **Integrations**: GitHub API (Octokit), LinkedIn API (SSID/OIDC), Gemini AI.
- **Data Layer**: Smart merging of integration metadata in `userProfileController.js`.
- **UI Architecture**: Added configuration modals and connection state management in `ProfileClient.tsx`.
