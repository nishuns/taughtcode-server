# Weekly Update: 2026-W12 - Enhanced Profiles & Chapter-Based Co-Authoring

## Overview
This week focused on deepening the "Collaborative Co-Authoring" experience and providing users with robust profile management tools, including extensive media support.

## Key Features

### 1. Chapter-Based Threaded Books
Refined the "Threaded Books" architecture to support structured publications.
- **Hierarchical Structure**: Books now support multiple named **Chapters**, each containing ordered **Pages**.
- **Research Papers**: Introduced a 'paper' type with a single nameless flow.
- **Explicit Ordering**: Implemented stable ordering via `pageIds` within chapters.
- **Refined Drafting Tool**: The `draft_chapter_page` tool now targets specific chapters and strictly follows a brainstorming-first workflow.

### 2. User Profile & Media Management
Significant expansion of the User Profile system to support rich personal and professional identities.
- **New Fields**: Added `coverURL`, `skills`, `gallery`, and `featured` items to the schema.
- **Media Uploads**: Implemented dedicated endpoints for profile picture and cover photo updates.
- **Personal Gallery**: Users can now maintain a gallery of photos and videos, with assets securely isolated in Firebase Storage.

### 3. Documentation & API
- **Complete API Coverage**: Added full documentation for Conversation and Book management endpoints.
- **Postman Sync**: Updated the Postman collection to reflect the new Chapter -> Page hierarchy and restored job tracking.
- **ERD Refinement**: Updated the system architecture diagram to include all new entities.

## Technical Improvements
- **Background Worker Logic**: Updated the page generation worker to be chapter-aware and utilize full conversation history for higher context accuracy.
- **Storage Isolation**: Standardized all user media paths to ensure clean asset management.
- **Branch Protection**: Enforced Pull Request reviews on `develop` to maintain high code quality.

## What's Next
- **Exporting Service**: Development of the PDF/EPUB generation engine for published books.
- **Interactive Editing**: Adding frontend tools for real-time chapter reordering.
- **Latency Optimization**: Deep dive into Firestore query performance.
