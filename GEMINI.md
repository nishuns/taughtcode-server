# Project: taughtcode-server

## Changes
1. Whenever you are done with a task, commit the changes to the repository.
2. In case of revert just revert back to last commit

## Agent Rules

1. whenever you are done with a task, commit the changes to the repository.
2. In case of revert just revert back to last commit

## Push Rules
1. **NEVER** push to `master`, `main`, or `develop` branches directly.
2. All changes **MUST** be made in a feature branch and merged via a Pull Request / Merge Request.
3. No exceptions, even for quick fixes or build errors.

## Branching Strategy

1. whenever I create a new branch it should be like <username>/<feature-name>
2. push branch to remote repository. if not mentioned 'EXPERIMENTAL'


## COMMIT RULES

1. Commit Messages should be like 'feat()/fix()/refactor()/docs()/style()/test()/chore(): <message>'
